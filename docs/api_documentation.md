# API Documentation

Base URL: `/api`

## Auth

- `POST /auth/login`
- `POST /auth/signup`

## News

- `GET /news`
- `GET /news/{news_id}`
- `POST /news`

## Prediction

- `POST /prediction/predict`

## Blockchain

- `GET /blockchain/status`
- `POST /blockchain/store`
- `POST /blockchain/verify`

## Reports

- `GET /reports`
- `POST /reports`

## Users

- `GET /users/me`
