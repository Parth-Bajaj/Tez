# Project Overview

Tez is a credibility-focused news platform that blends short-form reading with transparent verification.

## Goals

- Detect likely fake news automatically using NLP
- Store verification metadata in a tamper-resistant ledger
- Present news in a swipe-friendly, mobile-first UI
- Let users verify, save, and report stories quickly

## Modules

- Frontend: React + Vite short-form interface
- Backend: FastAPI APIs and business logic
- ML: TF-IDF + classifier training pipeline
- Blockchain: Solidity contract for content-hash storage
